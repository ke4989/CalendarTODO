# Roadmap

以下是 Calendar TODO 已记录的后续开发方向。计划会随实际使用反馈调整，不承诺交付日期；标为“评估”的方向尚未确定实施范围。

## 功能与日历体验

- 支持搜索本地事项和已缓存的 iCloud 日程。
- 支持在应用内创建 iCloud 日历及编辑日程提醒时间。
- 在确保数据安全的前提下，扩展 iCloud 原生重复日程的创建、单次及系列编辑能力。
- 评估按完成时间计算下一次本地重复任务，以及单次事项的字段与置顶覆盖。
- 增加可选的完成后提醒处理方式，在安全撤销和冲突保护就绪后支持移除后续提醒或仅保留原有开始时提醒。
- 完善未保存草稿在崩溃或重启后的恢复。

## 桌面清单与界面

- 持续改善 Desktop Companion 在不同桌面管理器、多显示器、虚拟桌面和缩放设置下的兼容性与焦点行为。
- 完善桌面清单与托盘的界面一致性、键盘操作和无障碍体验，并扩展现有主题。

## 同步与稳定性

- 在 iCloud 兼容性稳定的基础上扩展其他 CalDAV 服务，并完善同步冲突处理体验。
- 评估按时间范围下载日程以改善大日历的同步开销，同时保持完整性和删除判断安全。
- 评估应用完全退出后的 Windows 原生计划提醒能力。

## 安装与维护

- 持续完善 Windows 安装、升级与卸载兼容性。
